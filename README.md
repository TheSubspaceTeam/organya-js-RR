# Organya-JS-RR

**Forked from [Organya-js-QoL](https://github.com/idioticbaka1824/organya-js) by IdiotBaka**

A tiny and accurate player for Organya and Organya16 music files.

# Info

**Organya** is a chiptune music format created by [Daisuke "Pixel" Amaya](https://twitter.com/oxizn), meant for use in his [Cave Story](https://cavestory.org) game.

**[Organya-js](https://github.com/alula/organya-js)** is an accurate 250 SLoC JavaScript Organya player using Web Audio API, which was created by Alula.

**[Organya-js-QoL](https://github.com/idioticbaka1824/organya-js)** is a quality of life fork of Organya-js that made the UI better, with some improvements and ~400 LoC support and by IdiotBaka.

**[Organya-js-RR](https://github.com/MrRagtime/organya-js-RR)** is a fork of Organya-js-QoL which include some tracks from [Robot's Revenge](https://sites.google.com/view/projectemissaryplus/ProjectEmissaryPlus/CaveStory/RR) by Dr. Ragtime.

- See the demo: https://thesubspaceteam.github.io/organya-js-RR

## About Repository

- Organya.js - the main player component, it's all you need for playing `.org` files in browser. (~250 LoC)
- Organya-UI.js - optional component that renders a piano roll on HTML5 canvas. (~150 LoC)

UI graphics were taken from original Organya source code: https://github.com/shbow/organya / and from Baka's fork: https://github.com/idioticbaka1824/organya-js
